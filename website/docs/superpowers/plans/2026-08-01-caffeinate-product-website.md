# Caffeinate Product Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a deployable static product website for Caffeinate using the supplied application screenshots.

**Architecture:** Semantic HTML, authored CSS, small progressive-enhancement JavaScript, and a single release configuration file. No framework, package installation, remote font, analytics, or runtime dependency.

**Tech Stack:** HTML5, CSS, browser JavaScript, Python validation scripts.

## Global Constraints

- Product name remains `Caffeinate`.
- DMG is the primary installation method.
- Homebrew Cask is marked publishing in progress by default.
- Both supplied screenshots must be used.
- No invented metrics, testimonials, or compatibility claims.
- Site must be responsive and keyboard accessible.

---

### Task 1: Contract validator and configuration

Create `site-config.js` and `scripts/validate_site.py`. Validate required files, sections, screenshot references, install-state copy, focus styles, reduced motion, semantic landmarks, and local-only assets.

### Task 2: Semantic page structure

Create `index.html` with header, hero, proof strip, demo, features, technical explanation, installation, FAQ, and footer.

### Task 3: Impeccable visual implementation

Create `styles.css` using the documented warm editorial system, responsive breakpoints, focus states, and no prohibited generic landing-page patterns.

### Task 4: Progressive enhancement

Create `script.js` for screenshot tabs, mobile navigation, dynamic installation state, copy feedback, and current year.

### Task 5: Render and bounded repair

Render desktop and mobile screenshots, inspect one batch, repair only P0/P1 defects, and perform one confirmation render.

### Task 6: Clean release

Run the validator and syntax checks, write the Ralph run log and README, archive the site, extract it, and run validation again.

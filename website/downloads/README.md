# Website downloads

The redesigned site does **not** include or silently link to the local, unnotarized Caffeinate 3.0 beta DMG.

The published download path is controlled by `../site-config.js` and directs visitors to the repository's releases page. Homebrew refers to the separately published version.

To offer a 3.0 download later, first complete release verification, signing/notarization where required, and obtain explicit publication approval; only then update the site configuration and link to the real uploaded artifact. Do not put a placeholder DMG here.

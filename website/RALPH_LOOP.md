# Caffeinate Website Ralph Loop

## Pass 0 — Contract

- Define the product truth, page architecture, install states, visual direction, and release configuration.
- Add a deterministic repository validator before calling the site complete.
- Gate: every required section, asset, status label, and accessibility marker is specified.

## Pass 1 — Structure

- Build semantic HTML, authored CSS, screenshot demo, navigation, installation paths, and FAQ.
- Gate: markup contains all contract markers and both supplied screenshots are used.

## Pass 2 — Hardening

- Add keyboard behavior, mobile navigation, reduced-motion handling, copy feedback, configurable release URLs, metadata, and empty-download guidance.
- Gate: JavaScript syntax and repository validation pass.

## Pass 3 — Impeccable finish

- Render desktop and mobile fixtures.
- Audit hierarchy, contrast, clipping, overflow, interaction clarity, focus, copy, and generic AI-design tells.
- Apply at most one batched repair pass and one confirmation render.
- Gate: no P0/P1 visual defect remains.

## Pass 4 — Release

- Re-run deterministic checks, verify archive contents, compute checksum, and package only deployable files plus documentation.
- Gate: clean extracted archive passes the same validator.
